The [Alacrity SkillBuilder](https://github.com/Alacrity-Education/DemoBoards/tree/main/SolderingSkillbuilder) board is meant to teach students the basics of soldering before they attempt the [AirBox Station](https://github.com/Alacrity-Education/AirBoxV2/tree/main) soldering. 

**BEWARE**: intentionally includes both SMD and THT components.


You can find soldering instructions and schematic [here](https://wiki.alacrity.ro/en/Courses/AirboxBootcamp/solder-training).
